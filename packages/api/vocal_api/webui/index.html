Everything between audio and intelligence.

One registry, one API surface, one console. Model management, batch inference and realtime pipelines share the same weights and the same GPU.

Ollama-style model registry

Pull, list, inspect and delete voice models with commands you already know. Every catalog entry ships with license, commercial-use and VRAM metadata — so you know what you can ship before you download it.

vocal — shell

$ vocal pull hexgrad/Kokoro-82M

pulling manifest… ████████████████████ 100%

verifying weights… done

$ vocal serve

API ready at http://localhost:8000

OpenAI-compatible endpoints

/v1/audio/speech and /v1/audio/transcriptions are drop-in replacements. Point your existing SDK at localhost and keep shipping.

Realtime voice agents

Server VAD, streaming transcription, LLM reasoning and sentence-pipelined TTS over one WebSocket — with barge-in and per-turn latency metrics.

Your first voice model is one command away.

quickstart

$ pip install vocal-ai

$ vocal serve

→ console at http://localhost:8000/ui

The console runs entirely in your browser and talks to your local server. You can also use the hosted console on GitHub Pages — it connects straight to the Vocal instance running on your machine.
